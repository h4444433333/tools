# 规格 001 · 万物转文本 App（手机版）

> SDD 流程：**Spec（本文件）→ Plan → Tasks → 实现**。每完成一个任务回写「状态」。
> 最终目标（来自 Agents.md）：让不懂技术的人在手机上「拿文件 → 转成可读文本 → 发出去」，全程不离开本 App。

## 1. 已完成（基线）
- [x] **引擎核心** `mdcore`：责任链调度 + docx/html/csv/json 转换 + 魔数嗅探 + 说人话错误。7 测试全绿。
- [x] **App 壳骨架** Tauri v2：`#[tauri::command] convert` 已暴露，桌面 `cargo build` 产出可执行文件。
- [x] 三份讲解/设计文档入 `docs/`。

## 2. 需求（EARS 风格，按用户视角）

### R1 文件进来（来源）
- R1.1 当用户点首页「+」时，系统应弹出来源选择：本机文件 / 拍照 / 网址 / 粘贴文本。
- R1.2 当用户在 App 内浏览文件时，系统应只显示可转换类型，其余灰显标「不支持」。
- R1.3 当用户在安卓上打开「微信文件」时，系统应直接列出微信落盘目录中的文档（依赖原生权限）。
- R1.4 iPhone 因沙盒无法直读微信文件，系统应在首次遇到时给一次图文引导（导入到「文件」）。

### R2 转换
- R2.1 当用户选定文件点「转换」时，系统应调用引擎并显示进度，成功后进入结果页。
- R2.2 若为多文件或压缩包，系统应逐个转换并给出「成功 N / 失败 M」清单卡，失败附一句人话原因。

### R3 结果出去
- R3.1 结果页默认展示渲染排版，可切换到原始文本。
- R3.2 提供三键：复制给 AI / 存进 App 文件库 / 导出（md、PDF、长图）。
- R3.3 每次转换自动进「最近转换」列表，可重命名/删除/再导出。

### R4 非功能
- R4.1 离线可用：不填任何密钥，核心转换必须能跑。
- R4.2 界面手机优先，触控友好，避开刘海/底部安全区。
