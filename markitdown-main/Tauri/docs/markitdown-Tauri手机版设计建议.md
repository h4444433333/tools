# markitdown Tauri 手机版 · 产品与技术设计建议

> 定位：让不懂技术的人在手机上完成「拿到文件 → 变成能用的文本 → 发出去」全过程，零学习成本。
> 设计主线：围绕三个关键时刻 —— **文件怎么进来 / 进来后发生什么 / 结果怎么出去**。
> **总原则（已定）：全流程自闭环，全部动作发生在本 App 内，不依赖其他 App 的分享入口（不做微信「用其他应用打开」唤起）。**

---

## 一、产品原则（一票否决制）

1. **单屏单任务**：一屏只出现一个主行动按钮，不设"设置页"，高级选项全部藏进「⋯」。
2. **零选择**：用户永远不需要选"这是什么格式、该用哪个功能"，内部责任链自动分诊。
3. **错误说人话**：不出现堆栈、格式名词。统一句式："这个文件是加密的，请先解锁" / "这个文件暂时不认识"。
4. **离线优先**：不填任何账号/密钥，核心转换必须可用；云端能力（AI 看图、链接转换）是加分项不是地基。

## 二、关键时刻 1：文件怎么进来（App 内自建文件浏览器方案）

入口形态：首页大「+」→ 弹出**来源选择页**（九宫格卡片，每个来源一张卡）。

### ① 本机文件浏览（★核心：自己实现一个文件浏览器）
直接扫描并浏览手机上的真实目录，不弹系统选择器：
- **安卓**：「文件管理」App 能看到的目录我们都能列（需申请读取权限，一次授权永久可用）。
- **iPhone**：沙盒机制不允许随意翻全机文件。对策：对接系统「文件」App 的提供方机制，在自家浏览器里同时展示「App  Documents / iCloud 云盘 / 已连接的服务」——用户把文件存进"文件"后，这里都能翻到。
- 浏览器体验按"普通人"标准做：**只显示能被转换的文件**（其他灰掉标"不支持"）、顶部搜索框、按"最近收到/大小/类型"排序、多选打勾。

### ② 微信/QQ 文件怎么进来（不依赖对方分享入口）
- **安卓**：微信收到的文件本来就落盘在 `Tencent/MicroMsg/...` 等目录 → 自建浏览器里直接做一张**「微信文件」快捷卡**，点进去按时间列出所有微信收到的文档。完全自主，用户不用做任何"另存"动作。
- **iPhone**：微信文件在微信自己的沙盒里，任何 App 都无法直读（苹果限制，无解）。唯一路径是用户在微信里「文件导入到"文件"App」（微信自带此按钮），然后在我们 App 的 iCloud 云盘/"文件"里翻到。做法：首次使用时一个 30 秒图文引导（截图标注点哪里），之后常态化自助。

### ③ 网址下载
来源页放一张「网址/链接」卡：粘贴 http 链接 → App 自己下载 → 直接进转换流程。

### ④ 拍照转文字
拍单据、拍书页 → 走图片转换路径（本地 OCR 或可选 AI 描述）。补齐"文件还是纸质"的场景。

### ⑤ 粘贴文本
纯文本/HTML 直接粘进输入框就能转（复用原版的 data: URI 思路），零文件场景。

### ⑥ 拖拽（锦上添花，不做依赖）
iPad/安卓分屏支持从"文件"App 拖入；Android 侧可监听本 App 下载目录实现"拖到桌面文件夹即入库"。**MVP 放弃、V2 再补。**

## 三、关键时刻 2：进来之后（以 zip 为例）

```
丢进 zip
  → 自动拆开、逐个转（复用责任链递归思想）
  → 「清单卡」：✓ 3 个成功（可点开逐篇看） ✗ 1 个失败（一句人话原因）
  → 底部两个按钮：[合成一篇] [全部导出]
     · 合成一篇：每篇之间自动插分隔线+文件名标题
     · 全部导出：打包成一个 .md 或 zip（保留原名）
```

- 多文件同时拖入/分享 → 同样的清单卡，zip 与非 zip 混着来也统一处理。
- 转换中：显示大进度环 + "正在读第 2 个文件…"，可取消。
- 失败兜底分类：加密 → 提示解锁；超大 → 提示拆分；真不支持 → 明说并列出认识的格式（用图标展示，不用扩展名列表）。

## 四、关键时刻 3：结果怎么出去

| 按钮 | 行为 | 面向的场景 |
|---|---|---|
| **复制给 AI**（主按钮） | 复制纯文本到剪贴板，下方提示"切到 ChatGPT/豆包 粘贴即可" | 最高频真实用途 |
| **分享** | 调系统分享面板 → 微信/邮件/存到"文件" | 发给同事、存档 |
| **导出** | 三选：`.md` 原样 / 渲染后的 PDF / 长图 | 收不了 md 的人 |
| **预览/源码切换** | 默认显示渲染排版，可切到原始文本 | 顺便让用户看懂"md 就是带记号的纯文本" |

- **App 内「文件」库**：所有转换结果自动存进 App 的文档库（首屏"最近转换"就是它），永不过期，可重命名/删除/再导出。
- **iPhone 反向打通**：系统分享面板支持"存储到「转文本」"——别的 App 里的文件可以**存进**我们 App 的浏览器里（这是"引进来"，不违反"不依赖别人唤起"的原则，且是 iOS 上唯一让用户主动送文件进来的补充通道）。
- 长文阅读：结果页内目录锚点 + 字号调节（藏在 ⋯）。

## 五、界面结构（四屏闭环）

```
屏1 首页 = 「最近转换」列表 + giant「+」按钮（弹出来源选择页：本机浏览/微信文件(安卓)/iCloud与文件/网址/拍照/粘贴）
屏2 文件浏览器 = 目录树+筛选+多选 → [转换]
屏3 结果页 = 预览(默认) | 源码 切换 + 底部三按钮 [复制给AI][存进文件库][导出/分享]
屏4 单页设置(⋯进入) = 云端AI密钥(可选) / 首次微信引导图文 / 关于
```

全流程四屏闭环，任何一步都不需要离开本 App（iPhone 用户仅在文件躺在微信里时，需先在微信里点一次"导入到文件"——这是微信侧动作，我们 App 本身无依赖）。

## 六、Tauri 技术选型

### 总体架构
- **Tauri v2**（移动端官方支持 iOS/Android）。
- 分层：WebView 前端（UI，轻框架即可）↔ `invoke` 命令 ↔ **Rust 核心 crate（纯逻辑，不依赖 Tauri）**。
- 关键决策：转换引擎做成**独立 Rust crate + CLI 二进制**，Tauri 只是其中一个宿主 —— 引擎可单测、可复用（桌面 CLI、未来其他壳都用它），对应原版"库与壳分离"的架构优点。

### Python → Rust 依赖映射（逐能力核查过）
| 能力 | 原 Python 依赖 | Rust 方案 | 风险 |
|---|---|---|---|
| Office/EPUB/ipynb | python-docx/pptx/openpyxl | `zip` + `quick-xml` 自写薄解析层（格式本质是 zip+xml） | 低 |
| PDF | pdfplumber | `pdfium`（fork-geordie-cl 绑定）或 lopdf；pdfium 动态库三平台均有构建 | 中：注意打包体积 |
| 类型识别 | magika(ONNX) | 首选 `magic`/`infer` crate（魔数表）；高保真再上 `ort`（ONNX Runtime 支持 iOS/Android）跑 magika 模型(~2MB) | 中 |
| HTML→MD | markdownify | `html2md`/自写（规则可控，建议自写以贴近原输出） | 低 |
| 编码探测 | charset-normalizer | `chardetng` | 低 |
| 音频转写 | SpeechRecognition(上云) | **手机系统原生语音识别**：iOS SpeechAnalyzer / Android SpeechRecognizer（离线、免费、不引依赖）；MVP 可先砍 | 高：native 桥接 |
| 图片描述/OCR | llm_client 调多模态 | reqwest 调 OpenAI 兼容 API（用户自配 key）；纯 HTTP，无障碍 | 低 |
| YouTube/Wiki/RSS | 网络转换器 | 同上纯 HTTP+XML，放 V2 | 低 |

### 必须提前验证的三件事（按风险排序）
1. **安卓自建浏览器**：分区存储（Scoped Storage）下枚举/读取微信目录与公共下载目录的权限方案（MANAGE_EXTERNAL_STORAGE 或 SAF + 媒体权限组合），真机验证多品牌厂商差异。
2. **iPhone"文件"App 集成**：LSSupportsOpeningDocumentsInPlace + iCloud 云盘浏览，保证自建浏览器能真正列到用户的文件。
3. **pdfium 进 iOS/Android 包**：体积、审核、符号合规。

## 七、MVP 切法（建议）

- **MVP**：来源页（自建浏览器·安卓全量/iOS 文件App+iCloud）+ 网址下载 + 拍照 → Office/PDF/HTML/CSV/zip 转换 → 清单卡/预览/复制给AI/文件库/导出md。
- **V2**：拖拽、微信快捷卡增强、链接类转换（YouTube/Wiki）、音频、AI 图片描述、历史云同步、WebDAV 等外接网盘。
- 与 Agents.md 对齐：改造代码全部放 `markitdown-main/Tauri/`，引擎 crate、Tauri 工程、前端 UI 三个子目录独立，原始 Python 代码不动。
